# Training notes

- Structure: header (`Date`, `Trainee`, `Branch`), `**Status:**` line, then `1. Setup check`, `2. Courses` (or `2. Exercises` when the day has no course), `3. Key takeaways`, with `---` between sections. Match `docs/day-01.md`.
- Checkboxes are honest: unchecked = pending. Never tick something the trainee has not done.
- Never invent badge, artifact or verification links. Leave them out until the trainee supplies them.
- English, terse, in the trainee's own summarizing voice: tables and one-liners, not prose. Preserve that style when editing.
- Use the `day-note` skill to start a new day.
